# Sparrow 语言使用指南（v0.1.6）

> 面向"想用它描述一个模型"的人。本文里的每个例子都标了**能不能直接跑**：
> 正常例子都指向本仓库 `examples/` 下已存在的文件；故意写错的标 `❌`（用来说明诊断）。
> 下文 `sparrow` 指 `target/release/sparrow.exe`（`cargo build --release`）。
>
> 需要引擎的命令（`--asm`、`--backend lib`、训练）见 [README §2](../README.md) 的两种布局：
> 引擎默认取**本目录的上一级**（合并布局）或**同级 `vmlm`**（独立仓库），也可用
> `--vmlm-root` / `$env:SPARROW_VMLM_ROOT` 指定。

## 0. 三十秒版

```sparrow
模型 小:
  嵌入 词表=4054 维度=1536
  稀疏 维度=1536 连接=8
  线性 输出=4054
  连接 嵌入 稀疏 线性
  前向 嵌入 线性
```

```bash
sparrow examples/level2.sparrow                     # → .spar（架构 IR，默认输出）
sparrow examples/level2.sparrow --backend vml       # → .vml（opcode 序列）
sparrow examples/e2e_tiny.sparrow --asm <引擎>/target/release/vmlm-asm.exe \
        --consts-dir examples/e2e_bins -o out/e2e.vmb   # → .vmb（字节码）
sparrow examples/attn_t1.sparrow --backend lib --lang rust \
        --vmlm-root <引擎> --consts-dir examples/attn_bins -o out/aot   # → Rust 源码
```

四层后缀：**`.sparrow` 源码 → `.spar` 架构 IR → `.vml` opcode → `.vmb` 字节码**。

## 1. 五条语句就是全部语法

| 语句 | 写法（任选一种） | 说明 |
| --- | --- | --- |
| 模型头 | `模型 小:` / `网络 big：` / `model x:` | 不写也能编（隐式模型 `main`） |
| 层实例化 | `嵌入 512`（类型在前）· `e = 嵌入 512`（名字=类型）· `Embed(512, 4)` | 位置参数按类型绑定；也可全写命名参数 |
| 连接 | `连接 嵌入 稀疏 线性` · `把 e 连到 t 再连到 o` · `e -> t -> o` | 一条链；也用于声明残差（同一个层出现在多条链里） |
| 前向 | `前向 嵌入 线性` · `从 e 前向到 o` | 声明**入口与出口**；出口槽会被 `PRINT` |
| 重复 | `线性 输出=4 重复12次` · `... x 12` · `... 叠 12 个` · `... 复用12次` | 结构化节点，不是文本替换 |
| 损失 / 反向 | `损失 均方` + `反向` | V0.1.6 起是真语法（见 §8） |
| 自定义算子 | `算子 我的激活 = opcode(200) args(2)` | 只进 `.spar`；编到 opcode 会 `E101` |

**层类型只有 6 种**（都支持英文别名）：

| canonical | 别名 | 位置参数怎么绑 | 必填 |
| --- | --- | --- | --- |
| `EMBED` | 嵌入 / 嵌 / 词嵌入 / embed / embedding / emb | 1 个→`dim`；2 个→`vocab,dim` | `词汇表` 与 `维度` |
| `SPARSE` | 稀疏 / 稀 / 稀疏层 / sparse / sp | 1 个→`dim`；2 个→`dim,k0` | `维度` 与 `连接`(k0) |
| `LINEAR` | 线性 / 线 / 全连接 / linear / lin / dense / fc | 1 个→`out`；2 个→`in,out` | `输出`（`输入` 可从上游推） |
| `NORM` | 归一化 / 层归一化 / 范数 / norm / layernorm / rmsnorm / ln | `dim` | `维度`（**必须写**；只有 `线性`/`注意力` 的宽度能从上游推） |
| `ACT` | 激活 / 激活函数 / act / activation | `act` | `激活`（值如 `relu`/`tanh`/`sigmoid`/`silu`） |
| `ATTN` | 注意力 / 自注意力 / 多头注意力 / attn / attention / mha | 1 个→`dim`；2 个→`dim,heads` | `头`（`维度` 可从上游推） |

> 层类型**只做精确匹配**（不前缀匹配）：`Spars` 会报 `E002` 并建议 `Sparse`，
> 而不是悄悄当成 `SPARSE`。结构关键字与属性键则有"唯一前缀"匹配（`连`=`连接`=`conn`）。

## 2. 宽容语法：写起来像自然语言

这些写法**语义相同 ⇒ 产物逐字节相同**（验收 3/4/5/6/10 就是测这个）：

| 维度 | 都能写 |
| --- | --- |
| 语言 | 全中文、全英文、**中英混写**（`模型 resloop:` + `嵌入 词表=8`） |
| 标点 | `:` `：` `,` `，` `、` `;` `；` 混用；`()` `（）` `[]` 等价 |
| 缩进 | 2 / 4 / 8 空格、Tab、同一文件里不统一 —— 都行 |
| 块机制 | 冒号缩进 · `开始/结束` · `{ }` · `【 】` · 一行 `;` 分隔 |
| 数字 | 十进制整数与小数（`512` / `512.5`）；中文数字**单节**（`五`=5、`十`=10、`十二`=12） |
| 虚词 | `的` `个` `次` `就` `了` `让` `使` `将`（会被忽略：`叠 24 个`） |
| 真假值 | `是/否` `真/假` `1/0` `true/false`（`因果=是`） |
| 关键字当名字 | 用引号 `"m"`（**定义处与引用处通用**）；`@m` 只在**定义处**与 `连接` 里有效，`前向 @m` 会报 `E005`（实测） |

⚠️ **反面 1：两个静默误解析**（实测，**都不报错**）：
* 中文数字**逐位连写**不成立 —— `输出=五一二` 会变成 **2**（不是 512）；
* **不支持 `0x` 十六进制** —— `输出=0x200` 会变成 `out=0` 外加一个 `out=x200` 属性。
数字一律写十进制；宁可多写一位，别赌解析器。

⚠️ **反面 2：层类型别名/关键字不能当实例名**。`x` 是 `重复` 的别名，`lin`/`act` 是层类型别名，
`l`/`L` 是 `层` 的别名 —— 用它们当层名，报错会指向**下一行**
（`E005 重复 前面缺少被重复的层` / `连接至少需要 2 个层` / `E007`）。
见 [TRAPS C8](TRAPS.md)、C9、C10。安全做法：用 `l1` `h1` `mid` 这类名字。

## 3. 每种层做什么（以及它的常量）

| 层 | 产物（常量名以实例 `n` 为例） | 形状约定 |
| --- | --- | --- |
| `嵌入 词表=V 维度=D` | `n_E.bin` | `[V, D]` f32（int8 不支持，见 §9） |
| `稀疏 维度=D 连接=K` | `n_off.bin` `n_src.bin` `n_W.bin` | CSR：行偏移 `[D+1,1]`、列号 `[nnz,1]`、权重 `[nnz,1]`（f32 存整数） |
| `线性 输入=I 输出=O` | `n_W.bin` `n_b.bin` | `W [O, I]`（**NT 布局**：`y = x·Wᵀ`）、`b [1, O]` |
| `归一化` | `n_g.bin` `n_b.bin` | gamma/beta `[1, D]` |
| `激活 激活=tanh` | 无常量 | 逐元素 |
| `注意力 维度=D 头=H [序列=T] [因果=是]` | `n_Wq/Wk/Wv/Wo.bin`、`n_bWq/bWk/bWv/bWo.bin`、`n_scale.bin` | 四个投影 `[D, D]`；`n_scale` 是 `1/√(D/H)` |

* **常量全由使用者提供**（`.bin` 小端 f32）；编译器**不造数据、不做量化**。
  本仓库的 `tools/gen_*.py` 是确定性素材生成器（见 §11）。
* 注意力是前端用 `GEMM/SLICE/TRANSPOSE/SCALE/SOFTMAX/CONCAT` **拼出来**的：
  引擎里没有 `ATTEN` 这种指令。`维度` 必须能被 `头` 整除（否则 `E108`）；
  `头` 是必填（缺了 `E105`）。
* ⚠️ **`序列=1` 时 softmax 只有一个元素 ⇒ 恒等于 V**：这时 Q/K 投影**对输出没有影响**，
  拿来验证权重布局是测不出来的（我们在 int8 验收里被这一点骗过一次，见
  [REPORT_V015.md §11.3](../REPORT_V015.md)）。要测 Q/K 就用 `序列≥2`。

## 4. 属性：哪些真有用，哪些是静默 no-op

**生成器真正会读的键**（写了就生效）：
`词汇表(vocab)`、`维度(dim)`、`连接(k0)`、`输入(in)`、`输出(out)`、`头(heads)`、
`激活(act)`、`序列(seq)`、`汇入(merge)`、`因果(causal)`。

**只被解析、会出现在 `.spar` 里，但生成器不读**（对 `.vml`/`.vmb` **没有任何影响**）：
`隐藏(hidden)`、`层数(layers)`、`批大小(batch)`、`偏置(bias)`、`权重共享(tie)`、
`缩放(scale)`、`归一化类型(norm)`、`精度(eps)`。

自己验证这条（两条命令的产物哈希必须相同）：

```powershell
sparrow out/a.sparrow --backend vml -o out/a.vml   # 不带这些键
sparrow out/b.sparrow --backend vml -o out/b.vml   # 带上隐藏=8 层数=3 … 全部
(Get-FileHash out/a.vml).Hash -eq (Get-FileHash out/b.vml).Hash   # → True（静默 no-op）
```

> 这是**有意不假装**：与其"支持"一个没人实现的开关，不如在文档里说清它当前无效。
> 属性名的别名很宽（`维度/维/d/d_model/hidden_size/hsize` 都是 `dim`），
> 完整表见 `src/keywords.rs` 的 `ATTRS`。

## 5. 连接与汇入（残差 / 分支）

* **一条链**：`连接 嵌入 稀疏 线性` 等价于 `嵌入→稀疏→线性`。
* **多前驱 = 汇入**：一个层出现在多条链的末端时，前端先把它前驱的输出**合起来**再喂进去：

```sparrow
模型 resloop:              # examples/residual_loop.sparrow（能跑）
  嵌入 词表=8 维度=4
  t = 线性 输出=4 重复12次
  mg = 线性 输出=4
  连接 嵌入 t              # t 的输入
  连接 t mg                # 残差：mg 同时读 t 与 嵌入
  连接 嵌入 mg
  前向 嵌入 mg
```

* 汇入方式：`汇入=加`（`EWADD`）或 `汇入=拼`（`CONCAT`）；不写就按宽度自动定
  （宽度相同 ⇒ 加；不同 ⇒ 拼）。宽度不匹配又要求相加会报 `E100`。
* 拓扑校验：两个互不相连的入口（"两个链首"）报 `E102`；有层既不在数据流里也不成环报 `E102`。

## 6. 重复：默认展开，`--loop-repeat` 循环化

```sparrow
t = 稀疏 维度=4 连接=2 重复24次      # examples/loop24.sparrow
```

| | 默认（展开） | `--loop-repeat` |
| --- | --- | --- |
| 产物 | 24 份指令 | **1 份模板** + `LOOP_CNT`/`LAYERB`，指令数与层数**无关**（实测 76 → **19** 条） |
| 常量 | 24 份 `.bin` | 同样 24 份（汇编器按步长平移基址） |
| 数值 | 两条路必须**逐字符相同**（`tools/loop_ab.ps1` 守着） | 同左 |

* 源层（链首）**不能**循环化：需要一条链输入来播种进位槽 ⇒ `E110`（展开即可，行为不变）。
* 循环组的**每层权重必须不同**，否则步长写错也测不出来（`tools/gen_loop24.py` 用 24 个不同 seed）。
* lib 后端（Rust AOT）也支持循环组：Rust 侧是"一份 `forward` + N 份常量"。

## 7. 序列 `T>1`

`序列=T` 写在**链首层**上（如 `线性 输入=4 输出=4 序列=4`），整条链的激活变成 `[T, D]`。

* `嵌入` 在 `T>1` 时只能当**链首**：前端把它展开成"逐行查表 + 拼行"（T 次 `SLICE`+`EMB`）；
  出现在链**中间**会报 `E107`（那时输入已经是 `[T,D]` 激活，不是词元 id）。
* `稀疏` **不能**进 `T>1` 链路：`SPARSE_MATVEC` 是向量×矩阵，一次只吃一行 ⇒ `E107`
  （放着不管会**静默只算第一行**）。
* 输入常量是**一行 T 个 id/值**（`[T, D]`），见 `examples/seq_bins/`。
* 验收：T=3 的**每一行** == 该词元单独喂进去的 T=1 输出（逐字符），`tools/seq_ab.ps1`。

## 8. 训练：`损失` + `反向`（V0.1.6）

```sparrow
模型 tmse:                       # examples/train_mse.sparrow（能跑）
  l1 = 线性 输入=4 输出=4
  act = 激活 激活=tanh
  l2 = 线性 输入=4 输出=2
  连接 l1 act l2
  前向 l1 l2
  损失 均方
  反向
```

```powershell
python tools/gen_train.py                                       # 素材 + numpy 中心差分参考
sparrow examples/train_mse.sparrow --asm <引擎>/target/release/vmlm-asm.exe `
        --consts-dir examples/train_bins -o out/train/pristine.vmb
pwsh -NoProfile -ExecutionPolicy Bypass -File tools/train_ab.ps1  # 全套判据，退出码 0
```

生成什么：按**拓扑反序**发射 `MSE_BWD` → 每层 `GEMM_BWD_W`/`BIAS_BWD`（可加 `ACT_BWD`、
`GEMM_BWD_X` 把梯度往上游传），并把每个参数的梯度 `PRINT` 出来（训练步唯一的可观测输出）。

你需要知道的三件事：

1. **目标常量**是新的输入：`<模型名>_tgt.bin`，与出口同形状（`[1, out]` 或 `[T, out]`）。
2. **官方运行时跑不了**：`vmlm-runtime.exe` 是推理引擎，反向指令在 `#[cfg(feature="train")]`
   后面，对它 `exit=6 train feature disabled`。要跑训练步得用一份 `--features train` 的构建
   （`tools/train_ab.ps1` 会在 `out/` 下**隔离构建**，并用官方二进制哈希不变证明没动引擎）。
3. **边界**（硬失败，不是"注意一下"）：
   * 只接了 `线性` 与 `激活`；`归一化`/`注意力`/`嵌入`/`稀疏` 报 `E114`（列出支持范围）；
   * `反向` 与 `--slot-reuse`、`--loop-repeat` **互斥**（`E114`）：反向要读正向激活；
   * `--backend lib`（AOT）不支持反向（`E115`）；非 f32 权重不支持（`E114`）；
   * **没有参数更新**：`ADAM/SGD/ADAMW` 还不是语言的一部分，`训练` 这个词仍是命名边界 `E111`。
     现在能生成的是**训练步的梯度**，不是训练循环。

正确性判据是**中心差分**（不是"和另一份实现逐位一致"）：`tools/train_ab.ps1` 里
引擎解析梯度 vs numpy 中心差分，实测最大相对误差 **9.8e-06**。

## 9. 精度：f32 / bf16 / int8

| `--weight-dtype` | 作用于 | 只在哪条后端 | 说明 |
| --- | --- | --- | --- |
| `f32`（默认） | 全部 | 两者 | — |
| `bf16` | 线性层权重、嵌入表 | 两者 | 体积减半；加宽是精确的（bf16 = f32 高 16 位） |
| `int8` | 线性层权重、**注意力四个投影**（V0.1.6） | **只有 `--backend lib`** | `.vmb` 路径无此内核 ⇒ `E109` |

int8 的常量是**两个**：`n_Wq`（i8，1 B/元素）+ 每**输出行**一个 f32 scale
（`线性`：`n_scale`；注意力：`n_sWq` 这种带投影名的形式 —— `n_scale` 已被 softmax 的
`1/√(D/H)` 占用）。体积比 == 公式 `4/(1+4/K)`：K=4 时 2.0×，K=256 时 3.94×。

**量化不在编译器里**：`.bin` 由你提供（精确可表示时 f32 与 int8 输出**逐字符相同**，
这正是 `tools/int8_ab.ps1` 的判据）。

## 10. 两个后端怎么选

| | `.vmb`（`--backend vml` / `--asm`） | `--backend lib --lang rust` |
| --- | --- | --- |
| 产物 | opcode + 字节码，交给引擎执行 | 一份**普通 Rust crate**（含 `Cargo.toml`） |
| 依赖 | 引擎二进制（进程边界） | **静态链接引擎的 `vmlm-ops` 源码**（同一套算术内核） |
| 支持面 | 全部层类型 + 循环组 + 训练 | 全部层类型 + 循环组 + int8；**不支持** `反向`（`E115`） |
| 适合 | 部署/推理/训练步 | 集成进自己的 Rust 程序、标准工具链里调试 |
| 一致性 | 两边输出**逐字符相同**（`tools/lib_ab.ps1` 的 10 个模型守着） | 同左 |

性能口径（实测，D=256）：AOT 只比解释器快 **3%~8%** —— 两者调的是**同一套 AVX2+FMA 内核**，
而负载是内存带宽受限的。AOT 的价值是"产物不依赖引擎二进制"和"源码长度 O(1)"，不是速度。

## 11. 常量从哪来

```powershell
sparrow examples/e2e_tiny.sparrow --backend vml --args out/e2e.args
Get-Content out/e2e.args        # 每行：name:file.bin:rows:cols[:bf16|:i8]
```

* `--asm` 会把这份清单转成汇编器的命令行参数，`.bin` 的**相对路径以 `--consts-dir` 为基准**。
* 本仓库的确定性素材生成器（都用固定 seed，产物入库当指纹）：

| 脚本 | 生成什么 |
| --- | --- |
| `tools/gen_e2e_tiny.py` | 最小闭环（嵌入+稀疏+线性） |
| `tools/gen_loop24.py` / `gen_loop_two.py` | 24 层稀疏 / 两个循环组（每层不同 seed） |
| `tools/gen_residual.py` / `gen_seq.py` / `gen_attn.py` | 残差 / 序列 / 注意力 |
| `tools/gen_bf16.py` / `gen_int8.py` / `gen_int8_attn.py` | bf16 / int8（线性、注意力） |
| `tools/gen_train.py` | 训练步素材 + **numpy 中心差分参考** |

自己造常量：`python -c "import numpy as np; np.random.RandomState(0).randn(4,4).astype('<f4').tofile('l1_W.bin')"`
（记得小端 f32、行主序、形状与 §3 表一致）。

## 12. 命令行参考

```
sparrow <file.sparrow> [选项]

  -o, --output <PATH>   结果写到文件（默认 stdout）
      --emit-spar       输出架构级 .spar（默认）
      --backend vml     输出 opcode 级 .vml
      --args <PATH>     随 --backend vml 写出权重清单 name:file:rows:cols
      --loop-repeat     `重复 N` 走 LOOP_CNT + LAYERB（指令流 O(1)）
      --no-loop-repeat  关掉循环化（默认；= V0.1.1 的展开语义）
      --slot-reuse      激活槽按生命周期复用（激活区更小）
      --weight-dtype D  f32（默认）/ bf16 / int8（int8 只配 --backend lib）
      --backend lib     生成 Rust AOT 源码（配 --lang rust --vmlm-root [--consts-dir]）
      --lang rust       --backend lib 的目标语言（只有 rust）
      --vmlm-root <D>   引擎仓库根（生成代码依赖其 ops/ crate）
      --bench-iters N   给生成的 Rust 程序加计时循环（打印 avg us/iter = X）
      --asm <PATH>      一条命令跑全链：.sparrow → .spar → .vml → fork 汇编器 → .vmb
      --consts-dir <D>  权重 .bin 所在目录（默认 = 清单所在目录）
      --emit-ast-json   输出 AST JSON
      --emit-tokens     输出 token 流（调试宽容语法用）
      --sha256          同时打印输出的 sha256
  -h, --help            帮助

输入 `-` 表示从 stdin 读取。退出码：成功 0；失败 1（诊断打到 stderr）。
```

## 15. 十个最常撞的坑（完整 73 条见 [TRAPS.md](TRAPS.md)）

1. **`x` / `lin` / `act` / `l` 当层名** → 报错指向下一行（C8）。用 `l1`/`h1`。
2. **`序列=1` 测注意力**：softmax 恒等 ⇒ Q/K 不参与输出，测不出布局错（§3）。
3. **`稀疏` 或链中 `嵌入` 进了 `T>1`** → 硬报 `E107`（否则静默只算第一行）。
4. **权重形状/布局反了**：线性权重是 `[out, in]`，GEMM 是 NT（`y = x·Wᵀ`）。
5. **`.bin` 相对路径的基准是 `--consts-dir`**，不是当前目录；写相对路径时先确认。
6. **汇编器失败是 `panic=abort`**：退出码是**负数**（`0xC0000409`），脚本里别用 `u8` 装。
7. **引擎写死读同目录的 `model.vmb`**：跑之前先把它放到工作目录。
8. **`--slot-reuse`/`--loop-repeat` 与 `反向` 互斥**（`E114`）；想训练就别开。
9. **官方运行时不带 train**：训练步要 `--features train` 的构建（`exit=6` 就是它）。
10. **属性表里有一半是 no-op**（§4）：写了不生效，产物哈希不变。
11. **`五一二` / `0x200` 会被静默误解析**（§2 反面 1）：应写 `512`。

## 16. 自检：怎么知道"我没写错"

```powershell
cd sparrow
cargo test --locked                                             # 89 项
pwsh -NoProfile -ExecutionPolicy Bypass -File tools/verify_all.ps1   # 11 个驱动，退出码 0
```

`verify_all` 除了跑驱动，还断言一条**强不变量**：全部驱动跑完，工作区必须干净
（`examples/` 下的生成物入库当指纹 ⇒ 生成器不确定、或哪个驱动偷改工作区，都会红）。
在私有工作副本（不是 git 仓库）里这条会**显式打印 SKIP**，不会假装通过。
