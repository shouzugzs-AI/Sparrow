# 复查「只有 seed 1 能用」：你是对的，乱码 ≠ 坍缩 —— 但也不是"别的 seed 没学"

## 一、你的判断被数据证实：两种失败模式确实不同

我新加了 `--score-file`（**让模型给它自己生成的文本打分**，bits/char；复用同一条前向，不新增内核）：

| 生成文本（同一个 `01.cpk`，同一套权重）| 模型自评 bits/char | 不同字/100 |
|---|---|---|
| seed=1（连贯→`晶`循环）| **2.00** | 35 |
| greedy k=1（`天`×100 复读）| **5.02** | 1 |
| seed=2 乱码 | **14.11** | 88 |
| seed=3 乱码 | 11.78 | 64 |
| （参照）val 上的 CE | 6.53 | — |
| （参照）均匀地板 | 11.99 | — |

* **复读 = 模型很自信**（2.0 / 5.0 bits ≪ val 6.53）⇒ 它确实学到了这个环 ✓ 这才是**坍塌**
* **乱码 = 模型自己都认为"不可能是它生成的"**（11.8~14.1，**比均匀地板还差**）⇒ 这段文本**已经跑出模型学到的分布** ✓ 不是坍塌

所以我上一轮把它们混为一谈是**错的**，你的区分是对的。

## 二、但也不是"其他 seed 没学"（同一模型不存在"每个 seed 一个模型"）

* **模型学了**：val=**6.53** bits/char；而且 seed 1 的样本自评 **6.68** ≈ val 水平 ⇒ 正常样本就是 6.5 量级 ✓
* **采样器没坏**（这是关键对照）：把截断放开到**全支撑**（`--top-k 4054 --top-p 1.0 --temperature 1.0`）时
  seed 1 的样本自评 **6.68 bits**（= 模型自身熵水平，理论期望正是如此）✓ ⇒ 采样**确实按模型分布抽**
* 同一个采样器：
  | 设置 | 自评 bits/char |
  |---|---|
  | 全支撑 T=1.0, seed 1 | **6.68** ✓ |
  | 全支撑 T=1.0, seed 2 | 13.15 ✗ |
  | k=30 T=0.7, seed 2 | 12.51 ✗ |
  | k=1 贪心, seed 2 | 5.02（复读）✓ |

⇒ **结论**：模型学了，但**自由生成时大多数 seed 的轨迹很快跑出流形**；一旦跑出，条件分布退化到比均匀还差 ⇒ 乱码；
偶尔（seed 1）落在高频吸引子上 ⇒ 看着像"正常复读"。这正是 **exposure bias / 自由生成发散**，
在小模型 + 短训练 + 无重复惩罚下被放大。用你的词：**是"发散"，但是"生成轨迹发散"，不是"训练发散"**。

## 三、我排查并排除的两个具体嫌疑

1. **UNK 左填充**：generate 原来把不足 `seq` 的窗口左侧补 `UNK(0)`（62/64 是 UNK），而训练窗口里全是真实字符。
   已改成**用验证集真实字符补齐**（已改进、保留），但 junk 仍在（seed2 仍 94 个不同字）⇒ **不是主因** ✗
2. **采样读到错误的 logits 行**：检查过 —— 读的是最后一行（`par_b1_forward(&head, h.add(last*dim), …)`）✓ **正确** ✗

## 四、新增的实用工具：`--score-file`（生成质量闸门）

```cmd
.\target\release\vmlm-b1-full.exe <同样的模型/几何参数> --load-model artifacts\01.cpk --score-file artifacts\gen\某输出.txt
:: 输出 bits/char：~6-7 = 正常；11+ = 已跑出分布（这段生成不可信）
```
建议把它当成**生成质量指标**（比 val 更贴近"能不能用"），并纳入你的验收脚本。

## 五、按杠杆排序的修复建议

1. **repetition penalty / no-repeat-ngram**（采样器约 20 行）——直接治复读，让每个 seed 都能出可读文本。
2. **更强约束**：`temp 0.5~0.6 + top-k 10~20`（实测 k30/T0.7 仍 12.5 ⇒ 光靠截断不够），或加 **min-p**。
3. **训练端治本**：更多步数（自评方差这么大 = 没训够）；正规解法是 **scheduled sampling**（训练时用模型自己生成的上下文），
   但这要改训练循环——需要你点头。
4. 推理端把 `--score-file ≥ 8 bits` 视为"这次生成不可信"，自动重采样（简单有效）。

要我动手就说一声：**(i)** 加 repetition penalty + no-repeat-ngram + min-p（采样器，不动内核/训练）；
**(ii)** 加推理端"自评不过关就重采样"；(iii) 设计 scheduled sampling 的最小改动方案。
