## 2. 数据流（先画后写）

```
logits ← B1Model::forward
dlogits（CE 反向，仍在 trainer）
 ├─ head 反向： zero(dh); zero(head_dw, n_vocab*k0_head)
 │    稀疏:  head_blocked && fusion && nt_in<=1 → head_bwd_batched(...)
 │           head_blocked && fusion           → par_head_bwd(...)
 │           否则                              → par_b1_backward(&head, ..., dwp, fusion)
 │    稠密:  lm_bg += Σ_pos dlogits;  tr→btd/bth; gemm_nt(btd,bth,lm_g); tr(lm_w→bt); gemm_nt(dlogits,bt,dh)
 └─ for l in (0..layers).rev():
      [t8 边界] dh(token-major) ⇄ t8dyc(t8)   ← 由 t8_dh_token 决定方向
      [attn 层] zero(adx) ★一次;  sparse: zero(asq_g/ask_g/asv_g/aso_g) ★一次
                for w in 0..n_win_b:
                    [attn_backward_sparse_par | attn_backward]( asp+base, ...,
                        dh+base, adx+base, *_g + b*偏移, dwp | aat1/aat2/awt )
                attn_residual ? dh += adx : dh = adx
      [t8 分支] zero(dws[l]); zero(t8dxn); b1_backward_t8_avx2(src8, t8dyc → t8dxn, dws[l]);
                swap(t8dyc, t8dxn); continue
      [逐层]    xin = h_ins[l]; copy(dh → dy); relu 反掩码(用 pres[l]); zero(dx); zero(dws[l]);
                par_b1_backward(&scs[l], dy, xin, dws[l], dx, ..., dwp, fusion);
                no_res ? dh = dx : dh += dx
  末尾: if t8_stack && !t8_dh_token { transpose_t8_back_avx2(t8dyc → dh) }
```

★ = 清零**必须在窗口循环外**（2014-2016 的注释记录了第一版放在循环里导致只有 1/n_win 梯度被保留，FD 立刻抓到）。

## 3. 五条风险的精确落点（实测行号）

| 风险 | 落点 | 必须保住的语义 |
|---|---|---|
| **归约顺序** | `par_b1_backward(&head,...)` **1963**；`par_b1_backward(&scs[l],...)` **2099**；`attn_backward_sparse_par` **2035** | 每线程 dw 分段 + **固定线程号升序归约**；`nt_in`（region 体内并行度）**不能**换成 `nth`（2042-2049 注释：换错会让每步 24 次 8 线程 spawn） |
| **t8 交换** | 交换 **2084**；转置 **1989/1992/2075/2109** | `t8dyc`/`t8dxn` 必须作为**可变字段**由模型持有（逐层交换、垮迭代可见）；`t8_dh_token` 状态机方向不能反 |
| **attention 窗口切分** | 窗口循环 **2025-2062**；`n_win_b/t_attn_b` **2023-2024**；`woff/poff` **2027-2028** | 窗口**逆序**偏移 `(n_win-1-w)`；`apr = aprob.add(b*tt*tt + poff)`；`adx.add(base)`、`dh.add(base)` 逐窗口 |
| **清零位置** | `zero(adx)` **2012**；`zero(asq_g..aso_g)` **2017-2022** | 必须在窗口循环**外**（见 ★） |
| **head 双路径** | **1959 / 1961 / 1963** 三分支 | 选择条件 `head_blocked && fusion && nt_in<=1` → batched；`head_blocked && fusion` → par_head_bwd；否则 par_b1_backward。**head2 双路径不在本区** |

补充保真点：
* `dh` 在稠密逐层是 **赋值**（`no_res`）/ **累加**（否则）——不能统一成一种。
* `relu` 反掩码用**前向存下的 `pres[l]`**（`<= 0.0` 置 0），不是重算。
* t8 分支 `continue` 之后**不执行**逐层那段（两个分支互斥）。

## 4. 对账方法（本步的核心产物，先于任何数值验收）

写 `_opt/l4c3_reconcile.py`，机械对账两件事：

1. **逐 token 对比**：取原区（1949-2110）与新 `backward()` 函数体，各自
   ① 去注释/字符串 ② 统一空白 ③ 去掉 `self.` / `c.` 前缀与类型标注 → 生成 token 序列并 diff。
   目标是**零差异**；任何差异都要逐条解释（允许的差异只有：`self.x` 前缀、局部 `let` 的类型省略）。
2. **符号覆盖断言**：原区的每个自由标识符要么出现在新体内、要么在"已知 cfg/函数"白名单里；
   新体内的每个 `self.<name>` 都必须在结构体里声明。

> 这一步就是上一轮前向失败（`t8` 的 `dest` 应为 `dy` 却写成 `h_ins[l+1]`）的**机械防线**——
> 人的逐行核对会漏，token diff 不会。
