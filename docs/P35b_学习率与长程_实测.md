# P35 续：学习率、长程、等算力对照（2026-10-22 → 10-23）

> 本篇只做一件事：把 C 系列（keep=1%/5%/15% 的每 token 动态激活稀疏）与稠密基线
> 放到**各自最优学习率**下、在 600 / 1000 / 4000 步三个 token 预算上重新比一次，
> 并给出跨域、灾难性遗忘、Quill 架构的实测。
> 所有数字来自 `artifacts/p35`、`artifacts/p36` 的 `*.jsonl`，可用 `tools/p42_dump.py` 复现表格。

## 0. 结论先行

1. **最优学习率随稀疏率单调升高**：C15 ≈ 2e-3、C5 ≈ 5e-3（及以上）、C1 ≈ 5e-3；
   稠密小模型峰值在 1e-3，稠密 d=256 在 5e-3 开始明显变差。
2. **4000 步、双方都调过 lr**：C15（3.264M MAC/token）**4.3298**（3600 步，仍在降）
   对稠密 d=112（3.499M MAC）**4.6327**，**领先 0.285**，远超 0.098 的噪声地板。
3. **C5（1.874M）4.5496** 对稠密 d=80（2.008M）**4.6154**，领先 0.066 —— **在噪声地板内，只能算打平**。
4. **C1（1%）4000 步 5.3326，对稠密 d=64 4.6678 落后 0.665**：1% 是确定的负结果，长训不救。
5. **稠密在 ≤3.5M MAC 已经封顶**：d=64 4.6678、d=80 4.6154、d=112 4.6327（不单调），
   加宽到 3.5M MAC 也压不到 4.6 以下；d=192（8.95M MAC）仍在下降，但那是 2.7 倍算力。
6. **两次"稀疏优势消失"的旧结论都是口径错误**：拿未调 lr 的稀疏去比调过的稀疏/稠密。
   旧文 P35 §6.5、`实验数据总览_2026-10-22` 的相关段落以此篇为准。
7. 跨域：C15x 共用掩码 99.5%，但**核心通道重叠只有 0.661**（14.6/14.8 个通道各自专用）；
   C1x 直接崩（死通道 70%/66%）。
8. 遗忘：同等微调预算下稀疏的 wiki 回退只有稠密的 1/3–1/2（+0.20~+0.43 vs +0.63 nats），
   但起点不同（t=0 基线不同），只能读相对量。

## 1. 为什么先做学习率扫描

前一阶段两次得出"优势消失"：

| 时间 | 观察 | 当时的读法 | 真实原因 |
|---|---|---|---|
| 244 → 1000 步 | C15 从 −0.036 变成 −0.31（对 d112），但 C5/C1 转负 | "只有中等稀疏在短训有效" | 稠密臂与稀疏臂都停在 lr 3e-4，而这个 lr 对小 keep 明显偏小 |
| 1000 步等算力 | C5 对 d80 只打平 | "稀疏优势随训练变长消失" | C5@3e-4 是欠训；换 3e-3 后 1000 步从 6.094 降到 5.177 |

机制上的解释（**是解释，不是测量**）：掩码外的通道每步梯度恒等于 0，只有掩码内通道在积累二阶矩，
所以有效步长天然偏小，能承受的峰值 lr 更高。这个解释应由"最优 lr 随 keep 单调升高"来支持，
而该单调关系在 600 步与 1000 步两组阶梯里都成立（见 §2）。

## 2. 学习率阶梯（同 keep、同步数，只改 lr）

### 600 步（2.5M token）

| 臂 | lr | val |
|---|---|---|
| C1 keep=1% | 2e-3 / 3e-3 / 5e-3 / 1e-2 | 6.1013 / 6.0546 / **6.0014** / 6.0225 |
| C5 keep=5% | 2e-3 / 3e-3 / 5e-3 / 1e-2 | 5.5881 / 5.4797 / 5.4708 / **5.4680** |
| C15 keep=15% | 3e-3 | 5.2150 |
| 稠密 d=64 | 2e-3 / 5e-3 | **6.0977** / 6.1027 |
| 稠密 d=112 | 1e-3 / 5e-3 | 6.0037 / **5.9692** |

### 1000 步（4.1M token）

| 臂 | lr | val |
|---|---|---|
| C1 | 3e-4 / 1e-3 / 3e-3 | 6.6915 / 6.1209 / **5.8765** |
| C5 | 3e-4 / 1e-3 / 3e-3 | 6.0940 / 5.4982 / **5.1774** |
| C15 | 5e-4 / 1e-3 / 2e-3 | 5.5129 / 5.1285 / **4.9418** |
| 稠密 d=256 | 3e-4 / 1e-3 | 5.4299 / **5.0966** |

读法：
- 1000 步里唯一被调过 lr 的稠密臂是 d=256（1e-3 → 5.0966）。C15 用 **4.6 倍更少 MAC**
  做到 4.9418，领先 0.155 > 噪声地板。
- C15 在 2e-3 之后还没扫过更高；C5 在 1e-2 仍未见反弹（5.4680），说明 5% 的上限还没摸到。

### 4000 步（16.4M token，主轴）

| 臂 | MAC/token | lr | val |
|---|---|---|---|
| **C15** | **3.264M** | 2e-3 | **4.3298**（3600 步，跑中） |
| C5 | 1.874M | 1e-3 / 3e-3 | 4.6342 / **4.5496** |
| C1 | 1.319M | 3e-4 / 1e-3 / 3e-3 | 5.8772 / 5.6021 / **5.3326** |
| 稠密 d=64 | 1.409M | 3e-4 / 1e-3 | 5.3214 / **4.6678** |
| 稠密 d=80 | 2.008M | 1e-3 / 5e-3 | 4.6154 / **4.6141** |
| 稠密 d=112 | 3.499M | 5e-3 | 4.6327 |
| 稠密 d=192 | 8.947M | 1e-3 | 4.6890（1600 步，跑中） |

- C5 从 lr1e-3 到 3e-3 降了 0.085；C1 从 3e-4 到 3e-3 降了 0.54。同一份数据里
  **稀疏率越高，越依赖大 lr**，与 §2 的单调关系一致。
- 稠密 d=80 在 1e-3 与 5e-3 几乎同值（4.6154 / 4.6141）⇒ 稠密侧的最优 lr 已被夹住，
  不存在"稠密也被欠训"的漏洞。

## 3. 等算力 vs 等参数：两个口径必须分开说

| 口径 | 定义 | 结论 |
|---|---|---|
| 等 **MAC**（算力） | 每 token 乘加数相同 | **C 系列赢**：C15 3.26M 胜 d112 3.50M 0.285 nats；C5 1.87M 与 d80 2.01M 打平 |
| 等 **参数** | 参数量相同（C 系列恒为 d=256 → 14.69M） | **稠密 d=256 赢**：1000 步 5.0966 对 C15 4.9418 属同档，但 4000 步稠密 d=192/256 会继续降 |

C 系列的定位是"**拿参数换计算**"：权重全稠密（14.69M 参数，和 d=256 一样大），
但每 token 只算其中一部分，所以它的对手是**同算力的更窄稠密模型**，不是同参数模型。
这一点在 P32（B1 性价比）里已经栽过一次，这里明确写死。

## 4. 稠密侧的上限证据（≤3.5M MAC）

| d | 参数 | MAC/token | 4000 步最优 val |
|---|---|---|---|
| 64 | 1.31M | 1.409M | 4.6678 |
| 80 | 1.89M | 2.008M | 4.6141 |
| 112 | 3.33M | 3.499M | 4.6327 |
| 192 | 8.66M | 8.947M | 4.6890（1600 步，跑中） |

d=64 → 80 有 0.053 收益，80 → 112 反而回退 0.019。在 16.4M token 的预算下，
3.5M MAC 以内的稠密容量已经饱和在 4.61–4.63 一带。d=192 还在降（1600 步 4.689），
但它的 8.95M MAC 是 C15 的 2.74 倍，属于另一个算力档。

## 5. 跨域：wiki + 对话混合训练（700 步，2.87M token）

同一批数据交替取批，A = 维基，B = 对话；统计"只在 A 被选中 / 只在 B / 两域共用"的通道比例。

| 臂 | 死通道 A | 死通道 B | 仅 A | 仅 B | 共用 | 跨域重叠 | 核心通道重叠 |
|---|---|---|---|---|---|---|---|
| C1x keep=1% | **70.3%** | **65.5%** | 6.6% | 11.5% | 23.1% | 0.340 | 0.950 |
| C5x keep=5% | 16.9% | 23.7% | 12.9% | 6.1% | **70.2%** | 0.761 | 0.755 |
| C15x keep=15% | 0.39% | 0.10% | 0.10% | 0.39% | **99.5%** | 0.995 | **0.661** |

- C1x 是崩的：两域各有 2/3 通道在各自域里从未被选中，"跨域重叠"这个词在它身上没意义。
- C15x 表面看"完全共用"（99.5%），但**核心通道**（累计占比高的那批）有 14.6 / 14.75 个是
  各域专用的，核心重叠只有 0.661 ⇒ 领域分工发生在核心子集上，不在全集上。
- C5x 介于两者之间，共用 70.2%，核心重叠 0.755。
- 本组**没有跑稠密对照**，所以只能读稀疏臂之间的相对结构，不能读"跨域是否比稠密更抗遗忘"。

## 6. 灾难性遗忘：预训练 → 对话微调

微调数据为 fox 对话集，`wiki` 列是微调后在**维基验证集**上的 loss（回退越多说明忘得越多）。
t=0 是微调前的检查点，因此 Δ 只能在同一臂内部读（各臂起点不同）。

| 臂 | 微调步 | fox（微调域） | wiki（回退后） | 遗忘 Δ |
|---|---|---|---|---|
| 稠密 d=256 | 150 | 6.3442 | 6.7653 | **+0.626** |
| 稠密 d=256 | 400 | 5.7514 | 6.9940 | **+0.854** |
| C5 keep=5% | 150 | 7.4582 | 6.8973 | **+0.199** |
| C5 keep=5% | 400 | 6.8369 | 7.0910 | **+0.392** |
| C15 keep=15% | 150 | 7.0105 | 6.7252 | +0.302 |
| C15b keep=15%（长预训练） | 150 | 6.8937 | 6.4090 | +0.429 |
| C15b keep=15%（长预训练） | 400 | 6.1975 | 6.7827 | +0.803 |

- 同等微调步数下，稀疏臂的 wiki 回退是稠密臂的 1/3 ~ 1/2。
- 但"回退少"要和"微调不到位"一起看：C5@150 的 fox loss 是 7.4582，比稠密 6.3442 差 1.11，
  说明它在对话域几乎没学进去。所以这组数据的正确读法是
  **"稀疏臂更难被单一领域覆盖，代价是单领域拟合更慢"**，不是"稀疏更抗遗忘"的充分证据。
- C15b（更长预训练）回退变大（+0.429），说明预训练越充分、可回退的空间越大，符合预期。

## 7. Quill 架构（1000 步）

Quill = 周期性全注意力（每 K 层一次）+ 跨层共享读，见 `tools/p36_attnonce.py`。

| 臂 | 每层注意力 | MAC/token | 参数 | 244 步 | 1000 步 |
|---|---|---|---|---|---|
| Quill-1（`--attn-every 12`） | 只 1 层 | 11.831M | 11.81M | **6.3310** | **5.4552** |
| 稠密 d=256（全注意力） | 12 层 | 15.075M | 14.69M | 6.4897 | 5.5279 |
| Quill-L24（24 层，`c_L24_once`） | 1 层 | 21.268M | 21.26M | 6.3305 | — |
| Quill-T（24 层全注意力，`c_L24_tra`） | 24 层 | 28.051M | 27.29M | 6.5880 | — |

- 1000 步：Quill-1 比稠密 d=256 低 0.073，**小于 0.098 的噪声地板** ⇒ 只能算"打平，省 21% MAC"。
- 244 步：低 0.159（超过噪声地板），但 244 步太短，与本表其余结论不可同日而语。
- 层数翻倍（12 → 24）没有带来收益，Quill-L24 与 12 层同档。

## 8. 偏差与未决

- **单种子**。除 `A_dense256_s2` / `C_h_s2` 外全部 seed=1；噪声地板 0.098
  （同架构、同协议、只换初始化顺序的实测差），小于它的差距不作结论。
- **warmup 不一致**：长程臂 warmup=60，短臂 30。同档位内比较不受影响，跨档位读绝对 loss 要注意。
- **跑中臂**：C15@4000 只到 3600（4.3298 仍在降），d=192@4000 只到 1600（4.6890 仍在降）。
- **MAC 不含选择开销**：top-k 选择的实际成本未计入，墙钟数据不参与任何结论。
- **等参数口径未做齐**：稀疏松开参数后可以继续长到多少、与 d=256 同参数下能否反超，还没测。
- 跨域组缺稠密对照；遗忘组的 t=0 基线不统一，"抗遗忘"只能算弱证据。

指标定义见 P35 正文 §6.2 与本篇 §5、§6 的列名说明。
