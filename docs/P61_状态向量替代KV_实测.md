# P61 用状态向量替代 KV cache（Quill 主干上的七种状态形态实测）

> 背景：Quill（`docs/P57`、`docs/P60`）已经用「每个 token 只做一层 1-D 网络 + 每 12 层共享一次注意力」把
> prefill 的 MAC 压到 2.12×（seq=4096），但**长上下文 decode 仍要付一份 KV cache**：
> ctx=8192 时单层 fp32 KV 是 16.8 MB、每 token 4.45M MAC。
> 本实验把这一层注意力替换成**状态向量**（`S ∈ R^{h×hd×hd}` 或对角状态），让 decode 成本变成常数，
> 然后测质量到底掉多少、掉在哪一类状态上。

## 0. 结论先行

| | Quill 注意力 + KV | **选择性 SSM 状态** | 纯对角状态 | 线性注意力（=KV 压成状态） |
|---|---|---|---|---|
| seq=128 val@4000 | 4.1785 | **4.0694** | 4.2110 | 4.4790 |
| seq=4096 val@2000 | 4.8595 | （跑中） | **4.6398** | 5.2030 |
| decode 常驻内存 | O(ctx·d)，8k 时 16.8 MB | **O(1)，68 KB** | O(1)，68 KB | O(d²)，68 KB |
| decode 每 token MAC | 4.45M（ctx=8192） | **295K** | 295K | 295K |

1. **状态向量不是妥协方案，在 4000 步上比共享注意力好 0.109**（4.0694 vs 4.1785），同时 decode 从 O(ctx) 变 O(1)；
   序列越长优势越大（seq=4096：对角状态 4.6398 vs 注意力 4.8595，**−0.22**）。
2. **能用的状态形态很窄**：选择性 SSM > 块对角 ≈ 纯对角 >> RNN > GLA ≈ 线性注意力。
   **“把 KV 压成状态矩阵”的线性注意力是全场最差之一**（seq=128 差 0.30，seq=4096 差 0.34），
   因为 `φ=elu+1` 的核只能做平滑加权平均，没有精确召回，也没有遗忘。
3. **超参比结构更值钱**：只把 lr 从 1e-3 提到 4e-3，对角状态 1000 步从 4.755 → 4.633（0.12）；
   **长记忆初始化是负收益**（p∈(-6,1) 比默认差 0.10），短记忆初始化反而好。
4. 全部结论目前**单种子**，且 0.109 只刚越过噪声地板 0.098 —— 需要第二个种子或 lr 最优后的差距扩大才算定稿（见 §6）。

## 1. 实验口径

- 协议不变：d=256、L=12、heads=4、I=4d=1024、V=8198、seq=128、batch=32（4096 token/步），
  Adam(0.9,0.999)、per-tensor clip 1.0、warmup 60 + cosine、固定 4×32 验证批、16.4M token 预算
  （seq=128 是 4000 步，seq=4096 是 2000 步 × 8192 token）。
- 主干完全不动：每 token 的 MLP+残差、K=12 共享混合器、`inject=gain`、`mlp=gated`。
  **只替换那唯一一个 token 混合算子**，所以和既有 Quill 基线（`q_gain_min3e4_4000` = 4.1785）是单变量对照。
- 噪声地板 0.098（跨架构换初始化顺序），同架构换种子 0.0067。|Δ|<0.098 记「打平」。
- 筛选（1000 步）用于排序，定稿只看 4000 步 / 16.4M token。

## 2. 七种状态形态（`tools/p36_attnonce.py --mix state --state-kind K`）

| K | 递推 | 说明 |
|---|---|---|
| `lin` | `S_t = S_{t-1} + φ(k_t)v_tᵀ`，`o_t = φ(q_t)ᵀS_t / φ(q_t)ᵀz_t` | 线性注意力：KV cache 的**无损压缩形式**（外积累加），无衰减、无位置 |
| `gla` | `S_t = γ⊙S_{t-1} + φ(k_t)v_tᵀ` | 矩阵状态 + 固定衰减（按 key 维，log 间隔初始化） |
| `gla_dd` | `γ_t = σ(W_g x_t)` | GLA：衰减由输入决定 |
| `diag` | `h_t = a⊙h_{t-1} + (1-a)⊙Wx_t` | 纯对角状态，每通道一个时间常数（多时间尺度） |
| `diag+block16/32` | `h_t = A_blk h_{t-1} + b_t` | 块对角：A 初值为严格对角（=diag），可学出块内耦合 |
| `ssm` | `a_t = exp(−softplus(Δ_t)⊙A)`，`h_t = a_t⊙h_{t-1} + (1−a_t)⊙Wx_t` | **选择性 SSM**（Mamba/S6 简化版）：步长由输入决定，A 决定多时间尺度 |
| `ssm_g` | 同上 + 输出门 `σ(W_g x)` | 加 Mamba 的输出门 |
| `rnn` | `h_t = tanh(A h_{t-1} + Wx_t)` | 经典 RNN，状态是完整 d×d 矩阵 |

## 3. 1000 步筛选（seq=128，只用于排序）

| 臂 | 形态 | lr | val@1000 |
|---|---|---|---|
| `st_ssm_1000` | 选择性 SSM | 1e-3 | **4.596** |
| `st_ssmg_1000` | SSM + 输出门 | 1e-3 | 4.606 |
| `st_blk16_1000` | 块对角 16 | 1e-3 | 4.626 |
| `st_diag_lr4e3_1000` | 纯对角 | 4e-3 | 4.633 |
| `st_diag_lr2e3_1000` | 纯对角 | 2e-3 | 4.655 |
| `st_diag_phi4_1000` | 纯对角，短记忆初始化 | 1e-3 | 4.699 |
| `st_rnn_1000` | RNN（tanh 全矩阵） | 1e-3 | 4.715 |
| `st_diag_lr1e3_1000` | 纯对角 | 1e-3 | 4.755 |
| `st_gladd_1000` | GLA（输入门矩阵状态） | 1e-3 | 4.819 |
| `st_lin_1000` | 线性注意力 | 1e-3 | 4.843 |
| `st_gla_1000` | 矩阵状态 + 固定衰减 | 1e-3 | 4.853 |
| `st_diag_plo6_1000` | 纯对角，长记忆初始化 | 1e-3 | 4.857 |
| `st_diag_lr6e4_1000` | 纯对角 | 6e-4 | 4.874 |

同 horizon 的注意力参考（取自 4000 步臂 `q_gain_min3e4_4000` 内部的评测点，lr 曲线不同，只能看量级）：
step600 = 4.966、step1000 = 4.757。

筛选阶段的四条读数：

1. **lr 是一阶变量**：纯对角 6e-4 → 4e-3 是 4.874 → 4.633（0.24），且 4e-3 还没见顶。
   早期直接用 Quill 的 1e-3 跑状态臂，等于在次优 lr 上做结论。
2. **够用的矩阵结构 = 块对角**：同 lr 下块对角 16（4.626）比纯对角（4.755）好 0.13。
3. **族排序**：SSM > 块对角 ≈ 对角 >> RNN > GLA ≈ 线性注意力。
   “衰减是否由输入决定”只值约 0.04，而“有没有遗忘/多时间尺度”值 0.2 以上。
4. **初始化方向反直觉**：短记忆 `p∈(-2,4)` 好于默认 `(-4,2.5)`，长记忆 `p∈(-6,1)` 最差
   —— 这个规模/步数下长记忆通道学不动。

## 4. 4000 步定稿（seq=128，16.4M token）

| 臂 | 混合算子 | MAC/tok | 参数 | val@4000 | 相对 SSM |
|---|---|---|---|---|---|
| `st_ssm_4000` | **选择性 SSM**（lr 1e-3→3.3e-4） | 11.73M | 11.81M | **4.0694** | — |
| `q_gain_min3e4_4000` | 注意力 + KV（Quill 基线） | 11.83M | 11.81M | 4.1785 | +0.109 |
| 稠密 d224（const 1e-3） | — | 11.81M | 11.48M | 4.1596 | +0.090 |
| 稠密 d256（1e-3→3e-4） | — | 15.07M | 14.69M | 4.1169 | +0.031 |
| `qs_diag_4000` | 纯对角（lr 1e-3，未调） | 11.73M | 11.75M | 4.2110 | +0.142 |
| `qs_lin_4000` | 线性注意力（lr 1e-3） | 11.83M | 11.81M | 4.4790 | +0.410 |

- 对共享注意力 **−0.109**（刚过噪声地板），对同参数/同 MAC 的稠密 d224 **−0.090**，
  对算力多 28% 的稠密 d256 打平（−0.031）。
- 线性注意力在同条件下差 0.41，与筛选阶段一致，可判定失败。

## 5. 长上下文（seq=4096，2000 步 = 16.4M token）

| 臂 | 混合算子 | MAC/tok | val@2000 |
|---|---|---|---|
| `qs_diag_seq4096_2000` | 纯对角状态 | 11.73M | **4.6398** |
| `q_gain_seq4096_2000` | 注意力 + KV | 12.85M | 4.8595 |
| `d224_seq4096_2000` | 稠密 d224 | 22.48M | 5.0616 |
| `d256_seq4096_2000` | 稠密 d256 | 27.26M | 5.0845 |
| `c15_seq4096_2000` | C 掩码（每层注意力） | 15.45M | 4.8532 |
| `qs_lin_seq4096_2000` | 线性注意力 | 11.83M | 5.2030 |

**对角状态在长上下文赢注意力 0.22，赢稠密 d224/d256 0.42/0.44。**
这与 seq=128 的方向相反（那里状态只赢 0.11、甚至早期数据是打平），说明：

- 注意力在长上下文要做「精确召回」，靠的是 KV 里的原始 (k,v)；而**衰减记忆的平滑加权在 4k 上下文上反而更抗噪**；
- 2×d 的 `seq*d` 注意力核项（ctx 越大越贵）在状态方案里根本不存在，所以长上下文是状态方案的天然主场。

## 6. 未完成 / 必须声明的限制

| # | 项 | 状态 |
|---|---|---|
| 1 | SSM 在最优 lr（4e-3）下的 4000 步定稿 | 跑中（`st_ssm_lr4e3_4000`） |
| 2 | 纯对角在自己最优 lr（4e-3）下的 4000 步公平对照 | 跑中（`st_diag_lr4e3_4000`） |
| 3 | SSM 在 seq=4096 的定稿 | 排队（`st_ssm_seq4096_2000`） |
| 4 | lr 是否还要更高（8e-3） | 排队（`st_ssm_lr8e3_1000`） |
| 5 | 第二个种子（当前全部单种子） | 未排 |
| 6 | 解码内核实测（状态 vs KV 的墙钟） | 未做；本文只给精确计数：ctx 8192 时内存 16.8 MB → 68 KB（247×），每 token 4.45M → 295K MAC（15×） |

**限制原文**：4.0694 与 4.1785 的差是 0.109，仅比噪声地板高 0.011；而 diag 的 4.2110 是在**未调 lr** 下跑的，
所以“SSM 比对角好 0.14”这条也还混着 lr 差。§6 的第 1、2 条跑完之前，本文的“状态 > 注意力”只能算**强提示**，
不能当定稿结论引用。

## 7. 复现

```bash
# 筛选（1000 步，seq=128）
python tools/p36_attnonce.py --seq 128 --batch 32 --layers 12 --steps 1000 \
  --lr 1e-3 --min-lr 3.3e-4 --warmup 60 --attn-every 12 --share-attn 1 --inject gain \
  --mlp gated --mix state --state-kind ssm --threads 2 --tag st_ssm_1000

# 定稿（4000 步；把 --state-kind 换成 diag / lin / gla / gla_dd / ssm_g / rnn 即其余形态）
python tools/p36_attnonce.py --seq 128 --batch 32 --layers 12 --steps 4000 \
  --lr 1e-3 --min-lr 3.3e-4 --warmup 60 --attn-every 12 --share-attn 1 --inject gain \
  --mlp gated --mix state --state-kind ssm --threads 2 --tag st_ssm_4000

# 长上下文（2000 步 × 8192 token = 16.4M）
python tools/p36_attnonce.py --seq 4096 --batch 2 --layers 12 --steps 2000 \
  --lr 1e-3 --min-lr 3e-4 --warmup 60 --attn-every 12 --share-attn 1 --inject gain \
  --mlp gated --mix state --state-kind ssm --threads 2 --tag st_ssm_seq4096_2000

# 矩阵/初始化变体
#   块对角：  --state-kind diag --state-block 16
#   初始化：  --state-kind ssm --state-p-lo -2 --state-p-hi 4
```

结果在 `artifacts/p36/st_*.jsonl`（每行一条 `cfg`/`eval`/`final` 记录），`*_eff` 是 MAC 解析计数，
`state_*` 字段记录了形态与初始化参数。
