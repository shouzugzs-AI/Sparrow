# P35 动态激活稀疏：全部已有数据

> **本篇是 10-21 的中间快照，结论部分已被 `P35b_学习率与长程_实测.md` 修正**
> （当时所有臂共用 lr=3e-4，小 keep 被欠训）。本篇仍然有用的是**逐层明细**与**结构指标**；
> 数字汇总请以 `实验数据总览_2026-10-23.md` 为准，那是直接从 jsonl 生成的。

协议：d=256, L=12, heads=4, I=1024, V=8198, seq=128, batch=32 (=4096 token/步),
Adam(0.9,0.999), 每张量梯度裁剪 1.0, warmup 30, cosine 3e-4→3e-5，数据 artifacts/zh_wiki
（跨域臂加 artifacts/fox_sft），验证集固定 4×32 批。掩码 = 每 token 对 |RMSNorm(x)|
取 top-k，同层 qkv/gate/up/head 复用同一掩码；FFN 中间维单独一份掩码（keep_mid）。
MAC 为解析乘加计数；掩码 GEMM 用“掩码×稠密权重”精确模拟，不是近似。

## 8. 已知偏差与注意事项

1. 244 步 = 1.05M token，明显欠训练；同配置复跑差 0.04（t_v2b 6.8653 vs e_h05 6.9033，
   差异来自调度总步数 250 vs 244，不是噪声结论）。0.05 以内差值一律未验证。
2. 高算力端（>7.66M MAC）的等 FLOP 稠密值由最后两点外推，而稠密曲线在 d=152 后回升
   （6.6754 → 6.6861），说明大稠密模型欠训练，外推会系统性高估稀疏优势。
   可信区间：keep 15–40%、MAC 2–6.7M。
3. 旧口径 `dead_h`（全程累积）恒为 0，不能用来判断塌缩；v2 加了验证集口径。
4. 全部臂只跑 seed=1（seed=2 只做过 A_dense256_s2 6.6206 / C_h_s2 6.7026 两个对照）。
5. 速度数据不参与任何结论（机器有外部负载）。
