target dir : <repo>/target/bench

Only the `bench` feature gives vmlm-runtime its argv interface
(`<model.vmb> [reps[:slot]]` + an out.bin dump). The default build
ignores argv entirely: exit 0, no output file.

$ cargo build --release -p vmlm-runtime --features bench --target x86_64-pc-windows-msvc --target-dir <repo>/target/bench

   a PE TimeDateStamp and a fresh PDB GUID. Different sha256 across two
   builds is expected; see tools/p17_http_size.py section 2.)
