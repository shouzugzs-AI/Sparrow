P17-P4 PACKAGING OPTIONS -- server / cli / both
==============================================================================
root   = <repo>
crate  = vmlm-server  (bins: vmlm-server, vmlm-cli; lib: vmlm_server)

Both binaries link the SAME library, by design: json.rs, http.rs,
auth.rs, engine.rs, vmb.rs, tokenizer.rs, chat.rs live in the lib so
the CLI and the server cannot drift apart in their JSON or validation
behaviour. Consequence to state plainly: `--bin vmlm-cli` still
compiles the whole library, so 'cli only' is not a smaller build --
it is a build that produces one executable instead of two.
